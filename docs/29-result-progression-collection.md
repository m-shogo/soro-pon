# Result Progression and Collection

## Purpose

対戦後に、もう一局遊ぶ理由・デッキを調整する理由・コレクションを埋める理由を作る。

## Core Decision

```text
リザルトでコイン・称号・実績・クリアボード・コレクション進行を見せる。
ただし、コインでゲーム内の強さは買わせない。
```

## Result Screen Additions

```text

スコアボーナス
オールマイティ使用
合計点
獲得コイン
達成した実績

コレクション進行
次に狙える目標
```

## Coin Reward

MVPではシンプルにする。

```text
獲得コイン = totalPoints
1局の獲得上限 = 500 coins
流局 = 10 coins
敗北/CPU勝利時の参加報酬 = 10 coins
```

## Coin Usage

コインは強さではなく、見た目・称号・作成補助・コレクションに使う。

買えるもの:

```text
牌フレーム
牌裏デザイン
卓背景
カテゴリ色パレット
称号プレート
Resultスタンプ
効果音セット
役テンプレートの見た目
デッキカバー
クリアボード装飾
```

買えないもの:

```text
強い牌
高得点役
勝率アップ
CPU弱体化
オールマイティ増加
対戦中の有利効果
```

## Clear Board

クリアボードはマス目状の実績ボード。

MVPでは小さく始める。

```text
初期ボード: 5x5 = 25マス
```

例:

```text
初めて勝利する
ロンで勝つ
ツモで勝つ
2枚役で勝つ
3枚役で勝つ
9枚役で勝つ
13枚役で勝つ
14枚役で勝つ
特殊役を同時に2つ以上発動
オールマイティを使って勝つ
オールマイティなしで勝つ
同じ牌3枚ボーナスを発動
自作デッキを保存
カテゴリ色を5個設定
特殊役を10個作る
バランス警告を0にする
JSONを書き出す
通常版と拡張版を切り替える
```

## Collection

コレクションは、集めたくなる記録にする。

```text
一度でも上がったwin_role
一度でも発動したspecial_bonus
一度でも発動したscore_bonus
高得点Result Top 10
初達成Result
警告0のデッキ
```

## Result Actions

```text
[もう一局]
[デッキを調整]
[コレクションを見る]
[クリアボードを見る]
[TOPへ]
```

## MVP Scope

MVPで入れてよい最小構成。

```text
コイン獲得
称号数個
実績25マス
Role Collection
Result Album Top 10
見た目報酬のデータ型
```

MVPでまだやらない。

```text
課金
オンラインランキング
デイリー任務
期間限定イベント
ランダム報酬販売
強さに関係する購入
```

## Final Decision

- リザルト後にコインを付与する
- 獲得コインは基本totalPoints、上限500
- コインは強さではなく見た目/称号/作成補助/コレクションに使う
- クリアボード型の実績を入れる
- 役コレクションを入れる
- Result Albumを入れる
- MVPでは小さく始める
