# Vamp-pon In-world Game Direction

## Purpose

`soro-pon` のデザイン方向性を、単体の漫画風アプリではなく、Vamp-pon世界の中で流行っている遊びとして再定義する。

## Core Decision

```text
soro-ponは、Vamp-pon世界の中で住人たちが遊んでいる牌遊び。
```

アプリを漫画風に加工するのではなく、Vamp-pon世界の机の上に置かれた「記憶札ゲーム」を触っている体験にする。

## Why Previous Direction Did Not Fit

これまでの方向:

```text
漫画風UI
大人向け漫画UI
スタイリッシュUI
墨黒の対局
```

問題:

```text
見た目だけの加工になりやすい
soro-pon固有の理由が弱い
漫画風にしても世界観が空っぽだとダサく見える
Vamp-ponの強みである紙/インク/記憶/小さな光と切れてしまう
```

## New World Position

```text
Vamp-pon世界の子どもや旅人、街の住人が夜の灯りの下で遊んでいる小さな牌遊び。
忘れ物や記憶の欠片を札にして、組み合わせて役を作る。
```

ゲーム内での呼び方はまだ仮。

候補:

```text
記憶札
灯り札
忘れ札
旅札
soro-pon
```

正式名称は後で決める。

## Visual Concept

```text
夜の机
紙札
黒インク
小さなランタン光
手作りの盤面
記憶の欠片
静かな通常画面
勝負どころだけ少し派手
```

## What To Borrow From Vamp-pon

借りる:

```text
紙の質感
黒インク
小さな光
ランタンっぽい暖色
夜の静けさ
忘れ物/記憶のニュアンス
通常は静か、見せ場だけ派手
可読性優先
```

借りない:

```text
ヴァンサバのHUD
夜の街をそのまま背景にする
Vamp-ponのキャラ/ストーリーをそのまま出す
縦画面前提
常時派手な攻撃演出
```

## Tile Meaning

牌はただのカードではなく、記憶の欠片。

```text
tile = 記憶札
category = 記憶の種類
role = 記憶の組み合わせ
wildcard = どんな記憶にも寄り添う灯り/白紙札
discard = 場に置かれた記憶
collection = 一度見つけた記憶の記録
clear board = 夜の手帳に貼られた達成印
```

## UI Tone

### Base

```text
暗いが怖すぎない
紙とインク
暖かい光
静かな机
```

### Accent

```text
カテゴリ色はインク色/小さな封蝋/付箋色として見せる
オールマイティは小さな灯り色
コインは金貨ではなく、記録印/灯り粒でもよい
```

### Avoid

```text
派手な原色だらけ
安い漫画フォントだらけ
大人向けに寄せすぎた劇画
ソシャゲ報酬画面
子ども向けおもちゃ感
```

## Match Screen Direction

麻雀ベースは維持する。

```text
捨て牌は全員分すべて見える
中央に場を作る
最新の捨て牌だけ少し光る
山そのものは大きく出さない
残り枚数は小さく表示する
自分の手牌は下部に大きく表示する
相手3人は小さな手帳/札入れパネルとして表示する
```

漫画のコマ割りは使いすぎない。

```text
コマ割り = 情報整理のため
効果音 = ロン/ツモ/最新捨て牌など見せ場だけ
集中線 = 最新捨て牌/あがり/実績解除だけ
```

## Three.js Direction

Three.jsは世界観の補強に使う。

```text
札が少し浮く
最新捨て牌が机に落ちる
小さな灯り粒が舞う
黒インクがにじむ
Resultで記憶札が手帳に貼られる
Clear Boardのマスに灯りがともる
```

やらない:

```text
UI全部を3D化
Deck Editorを3D化
手牌を常時派手に回転
大量パーティクル常時表示
```

## Screen Implications

### TOP

「すぐ遊ぶ」よりも、夜の机に置かれた箱を開くような入口。

```text
古い札箱
灯り
今日の対局帳
```

### Deck Editor

ただの管理画面ではなく、記憶札を作る作業台。

```text
札を作る
インク色を選ぶ
組み合わせを記録する
役を手帳に書く
```

### Match

麻雀の卓 + 夜の手帳。

```text
中央: 場と捨て牌
下: 自分の記憶札
左右/上: 相手の札入れ
右下: アクションは小さく整理
```

### Result

勝敗表ではなく、対局記録。

```text
今日の記憶
完成した役
灯った印
手帳に貼られた達成
```

### Collection

図鑑ではなく、記憶帳。

```text
見つけた役
初めて完成した記憶
最高の対局記録
```

## Final Decision

- soro-ponはVamp-pon世界内で流行っている遊びとして扱う
- 単体の漫画風アプリにはしない
- 紙/インク/小さな光/記憶/夜の机を軸にする
- 麻雀ベースの情報配置は維持する
- 漫画表現は見せ場だけに使う
- Three.jsは小さな光/札の浮き/インク/Result演出に使う
- デザイン生成はこの世界観を前提にやり直す
