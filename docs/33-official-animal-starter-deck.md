# Official Animal Starter Deck

## Purpose

MVP公式サンプルとして、安全テーマの「動物スターター」を固定する。

実データ:

```text
samples/animal-starter.deck.json
```

## Core Decision

```text
公式サンプルは動物スターターを使う。
既存IP・第三者画像・外部URLは使わない。
画像なしで、emoji/fallbackLabelだけで遊べる。
```

## Deck Summary

```text
DeckProject: 動物スターター
総牌: 27種類 x 3枚 = 81枚
通常版: 8枚手牌 → 9枚あがり
拡張版: 13枚手牌 → 14枚あがり
共有JSON: 画像なし
```


## Normal Variant Roles

### win_role

```text
どうぶつ王国: 哺乳類6枚以上
海のパレード: 海の生き物5枚以上
空のなかまたち: 鳥4枚以上
小さなヒーロー: 虫4枚以上
つよいものクラブ: つよい5枚以上
```

### special_bonus

```text
サバンナ三兄弟: ライオン + ゾウ + キリン
かわいいトリオ: かわいい代表から3種
森のなかまたち: 森の動物から3種
```

### score_bonus

```text
同じ動物3枚
```

## Extended Variant Roles

拡張版は、2枚・3枚・10枚・13枚・14枚の動作確認ができる最小構成。

```text
2枚役: ライオンと星
3枚役: サバンナ集合
10枚役: どうぶつ大行進
13枚役: もうすぐ動物園
14枚役: どうぶつ王国完成
```

## Why This Deck

```text
カテゴリ色が分かりやすい
子どもにも伝わる
画像なしでも成立する
公式サンプルとして安全
通常版/拡張版の両方を検証できる
オールマイティを自然に説明できる
```

## Final Decision

- MVP公式サンプルは `samples/animal-starter.deck.json`
- 公式スクショもこのデッキを使う
- 既存IP検証デッキを公式スクショに使わない
- production buildには安全な公式サンプルのみ含める
