# Deck Variants and Balance

## Purpose

拡張ルールを入れる場合、通常デッキと拡張デッキをどう扱うかを決める。

結論:

- 拡張ルール用に完全な別デッキを最初から手作業で作らせない
- 通常デッキからコピーして拡張版を作れる導線を用意する
- ただし、標準ルール用デッキと拡張ルール用デッキは内部的には別variantとして扱う

## Why

標準ルールと拡張ルールでは、役設計が変わる。

標準ルール:

- 8枚手牌
- 引いた後9枚
- 3枚役中心
- 3枚セット×3組

拡張ルール:

- 13枚手牌
- 引いた後14枚
- 2〜14枚役
- 2枚役 + 12枚役などの分割
- 2枚役はツモ/ロン可能
- ポンなし
- リーチあり予定

同じ牌セットでも、役の作り方と点数バランスは大きく変わる。

そのため、同じ1つのdeckを無理に両対応させると、UIもvalidationもバランスも複雑になる。

## Recommended Model

デッキは1つの親情報を持ち、その中にvariantを持てるようにする。

```ts
type DeckProject = {
  version: 1;
  id: string;
  name: string;
  description?: string;
  tiles: Tile[];
  variants: DeckVariant[];
};

type DeckVariant = {
  id: string;
  name: string;
  ruleConfig: RuleConfig;
  roles: Role[];
  scoringNotes?: string;
};
```

ただしMVPでは、実装を簡単にするため `DeckDefinition` 1つでもよい。

将来的に以下のように移行する。

```text
DeckProject
  ├─ tiles: 共通牌セット
  ├─ variant: 通常ルール版
  └─ variant: 拡張ルール版
```

## User Flow

### Normal Flow

```text
動物デッキを作る
↓
通常ルールで役を作る
↓
遊ぶ
```

### Extended Flow

```text
通常デッキをコピー
↓
「拡張ルール版を作成」
↓
牌セットはそのまま
↓
役と点数だけ拡張向けに編集
↓
2〜14枚役、リーチ、重複ボーナスなどを調整
```

## UI Requirement

Deck Editorには将来的に以下の導線を置く。

```text
[このデッキをコピー]
[拡張ルール版を作成]
```

拡張ルール版を作成するときは、自動で以下を行う。

- tilesをコピー
- 既存の3枚役をコピー
- ruleConfigを `extended-hand` に変更
- 新しい役名/点数はユーザーが調整
- 2〜14枚役を追加できるようにする

## Naming

コピー時の名前例。

```text
動物スターター
動物スターター Extended
動物スターター 14枚版
動物スターター 拡張ルール版
```

日本語UIでは以下が分かりやすい。

```text
通常版
拡張版
```

## Balance Risk

拡張ルールは、かなり壊れやすい。

### 2枚役

良い点:

- 小さな関係性を表現しやすい
- すぐ成立するので気持ちいい
- ロン対象になると捨て牌に緊張感が出る

危険:

- 点数が高いと小役連打が最適になる
- 2枚役だらけになると14枚役のロマンが死ぬ

推奨:

- 2枚役は低〜中点
- 2枚役はコンボ補助の意味を強くする
- 2枚役だけで最高得点にならないようにする

### 14枚役

良い点:

- ロマンがある
- 自作デッキの見せ場になる
- SNS共有で強い

危険:

- 成立しなさすぎる
- 狙うとゲームが長くなる
- 高得点すぎると他の役が無意味になる

推奨:

- 14枚役は最高点でもよいが、成立難度に見合う点にする
- 14枚役だけが勝ち筋にならないようにする
- 小役と大型役の両方に意味を持たせる

### Ron

良い点:

- 捨て牌に緊張感が出る
- 2枚役や大型役にドラマが生まれる

危険:

- ロン候補が多すぎると毎回反応待ちになる
- CPUの捨て牌が馬鹿に見えやすい

推奨:

- ロン可能表示は分かりやすくする
- 反応時間は短くする
- CPUは最低限、明らかな危険牌を避ける余地を残す

### Duplicate Bonus

良い点:

- 同じキャラを集める意味が出る
- 推し集めが楽しい
- 直感的

危険:

- 同じ牌を集めるだけのゲームになる
- カテゴリ役が弱くなる

推奨:

- 上限を付ける
- ボーナス点を別表示にする
- デッキ編集時に警告を出す

## Balance Guardrails

Deck Editorに将来的に入れたい警告。

```text
2枚役の点数が高すぎます
14枚役の点数が低すぎるかもしれません
同じ牌ボーナスの上限がありません
ロン可能な2枚役が多すぎます
役が少なすぎてあがりにくい可能性があります
牌の総数に対して役が多すぎます
```

## Practical Recommendation

最初の実装では以下。

```text
MVP:
通常版だけ
3枚役だけ
8枚手牌 + 9枚あがり
ロンは標準ルールに必要な範囲で検討
```

次の段階。

```text
Deck copy:
通常版から拡張版を作成
牌セットをコピー
役はコピーしつつ編集可能
```

さらに後。

```text
Extended beta:
13枚手牌 + 14枚あがり
2〜14枚役
2枚役はツモ/ロン可能
ポンなし
リーチあり
重複ボーナスあり
```

## Final Decision

- 拡張ルール用にゼロから別デッキを作らせない
- 通常デッキからコピーして作れるようにする
- 内部的には通常版と拡張版をvariantとして分ける
- 1つの役表で通常/拡張の両方を無理に扱わない
- バランス警告をDeck Editorに入れる
