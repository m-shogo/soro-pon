# Deck Variants and Balance

## Purpose

通常ルール版と拡張ルール版をどう扱うかを固定する。

結論:

- デッキ入口は1つにする
- 通常版と拡張版は同じDeckProject内のvariantとして持つ
- 両方ある場合はワンクリックで切り替え可能にする
- 拡張ルール用に完全な別デッキを最初から手作業で作らせない
- 通常版から拡張版を作れる導線を用意する
- 通常版と拡張版は内部的には別variantとして扱う

## Why

標準ルールと拡張ルールでは、役設計が変わる。

標準ルール:

- 8枚手牌
- 引いた後9枚
- 3枚役中心
- 3枚セット×3組

拡張ルール:

- 13枚手牌
- 引いた後14枚
- 2〜14枚役
- 2枚役 + 12枚役などの分割
- 2枚役はツモ/ロン可能
- ポンなし
- リーチあり予定

同じ牌セットでも、役の作り方と点数バランスは大きく変わる。

そのため、1つの役表で通常/拡張の両方を無理に扱わない。

ただし、ユーザーには2つの別デッキとして探させない。

## Fixed Model

MVPからDeckProject方式を使う。

```ts
type DeckProject = {
  version: 1;
  id: string;
  name: string;
  description?: string;
  tiles: Tile[];
  variants: DeckVariant[];
  activeVariantId: string;
};

type DeckVariant = {
  id: string;
  name: string;
  label: '通常版' | '拡張版';
  ruleConfig: RuleConfig;
  roles: Role[];
  scoreBonuses?: ScoreBonus[];
  isExperimental?: boolean;
};
```

構造:

```text
DeckProject
  ├─ tiles: 共通牌セット
  ├─ variant: 通常版
  └─ variant: 拡張版
```

## User Flow

### Normal Flow

```text
デッキを作る
↓
通常版で役を作る
↓
遊ぶ
```

### Extended Flow

```text
通常版がある
↓
「拡張版を作成」
↓
同じDeckProject内に拡張版variantを追加
↓
牌セットはそのまま
↓
役と点数だけ拡張向けに編集
↓
2〜14枚役、リーチ、重複ボーナスなどを調整
```

## UI Requirement

Deck Detail / Match Setup / Deck Editor にはvariant切替を置く。

```text
[通常版] [拡張版]
```

表示条件:

- 通常版だけある場合: 通常版のみ表示
- 拡張版だけある場合: 拡張版のみ表示
- 両方ある場合: ワンクリックで切り替え
- 拡張版は experimental ラベルを表示

通常版だけ存在するDeckProjectには以下のボタンを出す。

```text
[拡張版を作成]
```

押した時の挙動:

- tilesは同じものを使う
- 通常版rolesをコピーする
- ruleConfigを `extended-hand` にする
- 拡張版variantを同じDeckProjectに追加する
- デッキ一覧上は1つのデッキカードのまま

## Deck List Display

Deck Listでは通常版/拡張版を別カードにしない。

1つのDeckProjectを1カードとして表示する。

表示例:

```text
デッキ名
対応: 通常版あり / 拡張版あり
現在: 通常版
警告: 2件
[遊ぶ] [編集] [通常版] [拡張版]
```

## Naming

variant名の例。

```text
通常版
拡張版
```

DeckProject名は共通。

```text
動物スターター
```

variant表示:

```text
動物スターター / 通常版
動物スターター / 拡張版
```

## Balance Risk

拡張ルールは、かなり壊れやすい。

### 2枚役

良い点:

- 小さな関係性を表現しやすい
- すぐ成立するので気持ちいい
- ロン対象になると捨て牌に緊張感が出る

危険:

- 点数が高いと小役連打が最適になる
- 2枚役だらけになると14枚役のロマンが死ぬ

推奨:

- 2枚役は低〜中点
- 2枚役はコンボ補助の意味を強くする
- 2枚役だけで最高得点にならないようにする

### 14枚役

良い点:

- ロマンがある
- 自作デッキの見せ場になる
- SNS共有で強い

危険:

- 成立しなさすぎる
- 狙うとゲームが長くなる
- 高得点すぎると他の役が無意味になる

推奨:

- 14枚役は最高点でもよいが、成立難度に見合う点にする
- 14枚役だけが勝ち筋にならないようにする
- 小役と大型役の両方に意味を持たせる

### Ron

良い点:

- 捨て牌に緊張感が出る
- 2枚役や大型役にドラマが生まれる

危険:

- ロン候補が多すぎると毎回反応待ちになる
- CPUの捨て牌が馬鹿に見えやすい

推奨:

- ロン可能表示は分かりやすくする
- 反応時間は短くする
- CPUは最低限、明らかな危険牌を避ける余地を残す

### Duplicate Bonus

良い点:

- 同じキャラを集める意味が出る
- 推し集めが楽しい
- 直感的

危険:

- 同じ牌を集めるだけのゲームになる
- カテゴリ役が弱くなる

推奨:

- 上限を付ける
- ボーナス点を別表示にする
- デッキ編集時に警告を出す

## Balance Guardrails

Deck Editorに入れる警告。

```text
2枚役の点数が高すぎます
14枚役の点数が低すぎるかもしれません
同じ牌ボーナスの上限がありません
ロン可能な2枚役が多すぎます
役が少なすぎてあがりにくい可能性があります
牌の総数に対して役が多すぎます
```

## Final Decision

- デッキ入口は1つ
- DeckProject内に通常版/拡張版variantを持つ
- 通常版と拡張版が両方ある場合はワンクリック切替
- 拡張ルール用にゼロから別デッキを作らせない
- 通常版から拡張版を作れるようにする
- 1つの役表で通常/拡張の両方を無理に扱わない
- バランス警告をDeck Editorに入れる
