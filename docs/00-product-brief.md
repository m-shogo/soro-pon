# Product Brief

## Working Title

`soro-pon`

## One-line Description

自分でデッキ・牌・役・得点を決めて、3〜4人で遊べるカスタム牌ゲーム。

## Core Promise

プレイヤーは好きなテーマで牌を作り、カテゴリを付け、役と点数を決め、そのまま対局で試せる。

このゲームの面白さは、単に勝つことではなく、以下のサイクルにある。

1. デッキを作る
2. 役を考える
3. 得点バランスにツッコむ
4. 友達に試してもらう
5. 改造して再共有する

## Target Experience

- 3〜4人で遊ぶパーティ牌ゲーム
- ルールは分かりやすい
- 役づくりは自由度が高い
- 画像がなくても絵文字と名前で遊べる
- 画像は各ユーザーが自分の端末で設定できる
- 共有は画像なしJSONで軽く行う

## Product Pillars

### 1. 自作が主役

このゲームの主役は、対局画面だけではない。

- Deck Editor
- Tile Editor
- Role Editor
- Scoring
- JSON import/export

これらが核。

### 2. 3〜4人用

2人専用にはしない。  
最初から3人戦・4人戦に耐える状態設計にする。

### 3. 画像なしでも楽しい

牌は以下の順で表示する。

1. ローカル画像
2. 絵文字
3. fallback label
4. 名前

ただし、牌の一番下には必ず名前を表示する。

### 4. 共有はルールだけ

共有JSONには画像を含めない。

共有するのは以下。

- 牌名
- カテゴリ
- 絵文字
- 枚数
- 役名
- 役条件
- 得点

画像は各ユーザーの端末で設定する。

## Non-negotiables

- 旧repoを参考にしない
- 既存IPデータを公式物に混ぜない
- 画像付き共有を作らない
- 3〜4人用を前提にする
- 自作デッキ・自作役・自作得点を最優先する
